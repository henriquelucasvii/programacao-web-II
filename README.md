# 🧑🏻‍💻 Programação Web II

Este repositório foi criado para armazenar, **organizar e documentar** as atividades e os exercícios práticos da disciplina de **Programação Web II**, referentes à obtenção de notas da primeira e segunda etapa do terceiro período.

## Objetivo do Repositório

Este repositório tem como finalidade:

- Centralizar os materiais produzidos durante o semestre  
- Auxiliar no acompanhamento do desempenho acadêmico e obtenção de notas  
- Facilitar o controle de versões dos códigos desenvolvidos  
- Servir como registro da evolução técnica adquirida na disciplina 

O objetivo deste repositório é centralizar os conteúdos produzidos ao longo do semestre, facilitar o controle de versões, além de documentar a evolução do aprendizado na disciplina de Programação Web II.
