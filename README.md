Este repositório foi criado para armazenar, organizar e documentar as atividades, seminários e exercícios práticos da disciplina de **Programação Web II**, referentes à obtenção de notas da primeira e segunda etapa do terceiro período.

## 🎯 Objetivo do Repositório

Além de ser um ambiente para centralizar entregas acadêmicas, este espaço serve como um portfólio da minha evolução técnica na disciplina. Os principais propósitos são:

* **Centralizar materiais** produzidos durante o semestre de forma acessível.
* **Facilitar o controle de versão** e o histórico dos códigos desenvolvidos.
* **Acompanhar o desempenho acadêmico** e as métricas de avaliação.
* **Documentar a aplicação de boas práticas** de programação e arquitetura de software ao longo do tempo.

## 🛠️ Tecnologias Utilizadas

O foco principal da disciplina é o desenvolvimento de aplicações web robustas no back-end. As principais tecnologias e ferramentas abordadas incluem:

* **PHP:** Linguagem base para a construção da lógica de servidor, manipulação de dados e requisições.
* **Bancos de Dados Relacionais:** (Ex: MySQL / PostgreSQL) para persistência de dados.
* **Servidor Web:** (Ex: Apache / Nginx) para o roteamento e hospedagem local.

## 🏗️ Arquitetura e Boas Práticas

Para garantir que o código seja limpo, escalável e de fácil manutenção, os projetos deste repositório buscam aplicar conceitos fundamentais de Engenharia de Software:

* **Orientação a Objetos (POO):** Utilização de classes, herança, polimorfismo e encapsulamento para estruturar o sistema em PHP.
* **Princípios SOLID:**
  * *Single Responsibility:* Cada classe ou método tem apenas uma responsabilidade.
  * *Open/Closed:* Código aberto para extensão, mas fechado para modificação.
  * *(A busca contínua por aplicar Liskov Substitution, Interface Segregation e Dependency Inversion nas implementações).*
* **Padrão MVC (Model-View-Controller):** Separação clara das responsabilidades da aplicação — isolando a regra de negócios (Model), a interface (View) e o controle de fluxo (Controller), preparando o terreno para o uso de frameworks modernos.
* **Código Limpo (Clean Code):** Nomenclatura semântica de variáveis e métodos, visando a legibilidade.
